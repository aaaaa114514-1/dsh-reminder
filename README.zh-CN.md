# DSH 提醒插件

[English](README.md)

这是一个面向 Windows DSH Desktop 的插件。当主会话需要用户处理、而 DSH 不在前台时，它会播放一次提醒音，帮助用户避免错过关键状态变化。

## 提醒事件

插件支持以下主会话状态：

- 等待权限或高风险操作确认。
- 等待用户回答澄清问题。
- 主任务完成。
- 主任务失败或被阻塞。

插件不会仅因为任务运行时间较长而提醒，也不会对未变化的状态重复提醒，不会单独提醒子代理事件。DSH 窗口处于前台时会抑制提醒。

## 设置

打开 **设置 -> 插件 -> DSH 提醒**，可以配置：

- 总开关。
- 每类提醒独立的声音开关和任务栏闪烁开关。
- 每类提醒独立选择内置提示音或已导入的 MP3/WAV 文件。
- 每类提醒独立调节音量并试听。

音量为 50% 时，与旧版本的默认提醒响度一致。导入的音频和每类事件的设置会在重启 DSH 后保留。插件热重载或 DSH 重启后，请先点击一次“试听”，以准备后台提醒所需的浏览器音频通道。

## 导入提示音

在插件设置卡片中点击 **导入 MP3/WAV**，选择本地音频文件。插件会保存一份内部副本，之后可在每类事件的提示音选择器中使用。单个文件大小限制为 10 MB。

## 平台说明

本插件面向 Windows DSH Desktop。

声音提醒在 renderer 中播放。原生 Windows 任务栏闪烁需要可选的 Desktop `dshDesktop.attention({ flash })` 桥接接口。如果当前安装没有该接口，任务栏闪烁控件会被禁用，但声音提醒仍然可用。

## 开发

安装依赖后运行：

```bash
npm run typecheck
npm run build:client
```

Host 入口可以使用 TypeScript 编译：

```bash
npx tsc -p tsconfig.json
```

本仓库主要用于 DSH Desktop 本地开发注入。请使用你的 DSH 开发环境提供的插件注入流程加载构建后的 `lib/` 文件。
